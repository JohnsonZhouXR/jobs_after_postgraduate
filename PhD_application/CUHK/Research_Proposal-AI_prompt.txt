具体地来说，分为下面这些步骤：
【Biomedical Algorithm】
1.利用Finite Element Analysis来分析与骨科相关的结构力学，学习使用Abaqus（用于Complex material simulation和Nonlinear mechanics场景）和Ansys（用于Multi-physics coupling (fluid/thermal/electromagnetic)和Fast simulation场景）等软件
2.Molecular Dynamics，利用分子动力学（具体使用工具GROMACS）模拟研究肢原分子的力学特性，得出软骨微观结构成分（关节软骨;胶原分子）的力学特性与宏观力学特性（杨氏模量等）的关系
3.Biomedical Image Processing，可以使用Classical方法来获取医学图像中目标的各种特性（如Circularity、Rectangularity、Area/Perimeter、Skeleton），当然还有时下最火热的AI技术，可以实现图像中对目标的Segmentation、Detection和Classification。

【Engineering】
1.Image Processing Integration
Integrate image processing with camera image capture, communication, inference, result display & feedback, and UI interaction into an automated software workflow, eliminating the need for separate operation of each link on different devices.

2.Image Auto Collection & Sorting
Use classification models or preset rules to automatically name, classify and store collected images and data, serving subsequent data processing, model training & validation, and data augmentation.

3.User Friendly Interface Software Development
Develop visual interfaces via QT or similar tools, encapsulate complex algorithms and processes, and lower the threshold for medical staff and technicians to use AI and algorithms.

4.AI System Deployment & Adjustment
Deploy adaptive versions based on computing power and platforms of different clinical scenarios to ensure algorithm coverage across various application scenarios.

5.AI Acceleration
Depending on project requirements, accelerate model training, inference validation in the lab, and speed up offline clinical inference using methods like CUDA, TBB multi-threading, or AVX instruction set optimization.

【Clinic】
1.Medical Image Analysis，可以在X-Ray、CT、MRI等医学影像上助力。
As mentioned above, an integrated system that combines image acquisition, algorithmic inference, and result display & transmission can be built for both online and offline clinical scenarios. At the same time, data is automatically collected, classified and stored to support subsequent offline model training and data augmentation.

2.Implantable Sensing
Dynamic monitoring of implant-related parameters (Temperature, Humidity, Pressure) and human body parameters (Tissue Strain, Joint Angle, Tendon Tension, Bone Load, pH Value, Blood Oxygen Saturation, Blood Glucose Concentration, Body Fluid Ion Concentration) not only assists in assessing tissue metabolic status and implant degradation environments but also enables feedback of monitored data to MD or FEA as input parameters or calibration references. This helps enhance the realism and accuracy of simulations, optimize implant design, predict postoperative complications (e.g., loosening caused by stress concentration), and provide data support for customized treatment plans.
